# Flunora/.github

Organization-wide defaults for the Flunora GitHub organization.

| Path | Purpose |
|---|---|
| `profile/README.md` | The public profile shown at [github.com/Flunora](https://github.com/Flunora) |
| `CONTRIBUTING.md` | How to reach the team |
| `SECURITY.md` | How to report a vulnerability |
| `CODE_OF_CONDUCT.md` | How we treat each other |
| `SUPPORT.md` | Where to get help |
| `pull_request_template.md` | The default pull request description |
| `ISSUE_TEMPLATE/` | Bug report and feature request forms |

GitHub applies these files to any repository in the organization that does not define its own. A repository can override one by adding a file with the same name at its root, in `docs/` or in `.github/`.

This repository is public because the organization profile must be. Never commit internal information here: no hostnames beyond the public ones, no infrastructure details, no customer data.
